Timing check: tap along to the clicks so the notes line up with what you hear.

You'll hear 4 count-in clicks, then 12 more. Tap any play key on each of the 12. The game measures how late your speakers and fingers are, and shifts the notes to match.

My calls, tell me if any are wrong

  • The numpad, arrows, F-keys and nav keys are drawn so the picture matches your keyboard, but they're never used for playing. Only the main block plays, split in the gap between G and H.
  • Levels: 1 = 2 lanes, 2 = 3, 3 = 4, 4 = 5, 5 = 6.
  • Keys are matched by where they physically sit, so any language layout works.
  • Line-up is saved as a fraction of your screen width, so it holds whenever the game runs full screen on that monitor. The game shows it full screen, and this page is narrower, so use FULL SCREEN to try it for real.
  • Setup is saved. You can rerun it from the SETUP tab, and you only need to redo the timing check if you switch speakers or headphones.
